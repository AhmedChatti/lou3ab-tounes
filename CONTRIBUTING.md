# Help improve Lou3ab Tunisia

Thank you for helping Tunisians and visitors learn more about the country! 🇹🇳

## Report a mistake

Open an [issue](../../issues) and tell us:
1. which game, and the date of the puzzle if it's a daily one,
2. what is wrong,
3. a link to a reliable source with the correct information.

## Suggest something

Ideas are welcome:
- a personality, a dish, a festival, a footballer or a historical event that should be in the games,
- another way of spelling a name that the game didn't accept,
- an idea for a new game.

Open an [issue](../../issues) or write to [Ahmed Chatti on LinkedIn](https://www.linkedin.com/in/ahmedchatti/).

## Our rules for content

- Every fact needs a reliable source. When sources disagree, it stays out.
- Texts in English, French and Arabic.
- Song titles only, never lyrics. No photos without the right to use them.
